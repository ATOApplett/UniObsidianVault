### Week 8 task 5
**a) Stable for all K:** **Task 1, Task 2, Task 4**  
Each has asymptotes that keep the locus entirely in the left-half plane (vertical asymptotes for Tasks 1–2; the single −180° asymptote plus zero-terminated branches for Task 4). Task 3 fails because its ±60° asymptotes cross into the right-half plane for large K.

**b) Oscillatory step response for any K:** **Task 2, Task 3**  
Both start with complex-conjugate open-loop poles that never return to the real axis for any positive K (no valid real-axis breakaway exists near them), so the dominant poles are complex for every gain. Tasks 1 and 4 begin with real poles and only become complex above a certain gain, so they don't oscillate for _every_ K.

**Task 2 is the only system satisfying both (a) and (b)** — always stable _and_ always oscillatory.
